# Simple C++ Tic-Tac-Toe ❌⭕

A lightweight, console-based implementation of the classic **Tic-Tac-Toe** game written in C++. This project is designed to be simple, readable, and beginner-friendly, avoiding complex data structures or external graphical libraries to focus purely on core programming logic.

---

## Features
* **Two-Player Local Mode:** Alternates turns between Player `X` and Player `O`.
* **Interactive Console Board:** Displays a clear 3x3 grid numbered 1 through 9.
* **Smart Input Handling:** Prevents players from overwriting already taken spots or entering invalid choices.
* **Automatic Game State Detection:** Instantly recognizes row, column, and diagonal wins, as well as ties.

---

## Getting Started

### Prerequisites
You need a C++ compiler installed on your system (such as **g++** via MinGW on Windows, GCC on Linux, or Clang on macOS).
